# Mom's Cloud Kitchen

Marketing site for **Mom's Cloud Kitchen** — home-style Indian meals and franchise opportunities in Vasai-Virar. Built with Vite, React 19, TypeScript, and Tailwind CSS v4.

## Prerequisites

- **Node.js >= 20.19** (Node 24.x recommended; Vite 8 requires >= 20.19)
- npm

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

Serves the app on `http://localhost:3000` (bound to `0.0.0.0`).

> Scripts call `node` directly with relative paths so they work even when the project folder path contains special characters such as `&`.

## Build

```bash
npm run build
```

Outputs a static production build to `dist/`.

## Typecheck

```bash
npm run typecheck   # or: npm run lint
```

Runs `tsc --noEmit`.

## Preview

```bash
npm run preview
```

Serves the built `dist/` locally.

## Deploy

### Hostinger

1. Run `npm run build`.
2. Upload the **contents** of `dist/` (not the folder itself) to your `public_html` directory.
3. `public/.htaccess` is copied into `dist/` by Vite and provides SPA rewrites, MIME types, compression, caching, and security headers.

### Vercel

Import the repository and deploy. `vercel.json` already configures the Vite framework, SPA rewrites, and cache headers.

## Environment variables

Copy `.env.example` to `.env.local` and fill in as needed. Only `VITE_`-prefixed variables are exposed to the browser.

| Variable | Required | Description |
| --- | --- | --- |
| `VITE_META_PIXEL_ID` | No | Meta (Facebook) Ads Pixel ID. If unset, the pixel is skipped and the site works normally. |

## Project structure

```
project/
├─ public/            # Static files copied as-is (incl. .htaccess)
├─ src/               # React app source, components, data, utils
├─ index.html         # HTML entry point
├─ vite.config.ts     # Vite configuration
├─ vercel.json        # Vercel deployment configuration
├─ tsconfig.json      # TypeScript configuration
├─ .env.example       # Environment variable template
└─ dist/              # Generated build output (not committed)
```

> `dist/` is generated by `npm run build` and should not be edited by hand or committed.
